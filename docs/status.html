3. 確定している制度上の事実

括弧付きの数字は内数

軽自動車がある場合、その数は内数として括弧書きされる。自動運行旅客運送または 特定自動運行旅客運送に使う自動車がある場合も、その数は内数として該当欄に記載される。 このため count_kei <= count は様式上の不変条件となる。

登録番号の構造

事務・権限が国にある場合は、〔運輸局の頭1文字〕〔運輸支局の頭1文字〕 〔種別1文字〕第〔一連番号〕号で構成される。種別は「福」が福祉有償運送、 「交」が交通空白地有償運送。

運送種別ごとの車種区分

福祉有償運送は寝台車、車いす車、兼用車、回転シート車、セダン等の5区分。 交通空白地有償運送はバス（定員11人以上）と普通自動車（定員11人未満）の2区分。

  • 福祉有償運送の登録に関する処理方針について（国自旅第317号、最終改正 国自旅第197号） 001766049.pdf
  • 交通空白地有償運送の登録に関する処理方針について（国自旅第316号、最終改正 国自旅第199号） 001766048.pdf
  • 記録箇所: run_record.md §3.1
