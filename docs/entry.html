UDC2026 作品① / 応募説明

山口県
市町別の登録供給ビュー

公共交通の計画を考える前に、「地域にどんな移動サービスが登録され、どのくらいの予定運行がデータに入っているか」を、根拠と日付を分けて確かめるための静的Webアプリです。

作品タイプ: アプリケーション 作品テーマ: 道路・交通 対象地域: 山口県
公開デモを使う 協議前確認メモを作る 岩国市・光市の比較を見る 検証状況を見る
作品概要（81字）

山口県の公共交通担当者・事業者向けに、分散した登録簿と公式GTFSを市町別に整理し、輸送供給・日付・根拠・データの限界を同じ画面で確認できる静的Webアプリです。

Problem

解決したい問題

県や市町が地域の移動手段を考えるとき、最初に必要なのは「今、どんなサービスと予定運行が確認できるか」という土台です。しかし、その情報は一か所にはありません。

登録簿で分かること

自治体やNPOなどが行う自家用有償旅客運送について、登録団体、運送区域、登録車両を確認できます。

GTFSで分かること

バスなどの予定時刻や乗降場所を、共通形式のデータとして確認できます。ここで扱うのは実績ではなく予定です。

なぜ、そのままでは比べにくいのか

登録簿とGTFSは公開場所も数え方も違い、ページに書かれた日付、ファイル内部の日付、検証した日も別です。資料を行き来すると、どの日付と範囲の数字かを取り違えやすくなります。

Users and value

誰が、何のために使うか

県・市町の公共交通担当者

計画や事業者との協議の前に、公開資料で確認できる供給側の情報と、その根拠・不足を整理するために使います。

交通事業者・地域の関係者

自治体単位の登録情報と、確認できたGTFSの予定運行を同じ入口から追い、次に確認すべき資料や論点を共有するために使います。

How to use

3段階の使い方から、協議前確認メモまで

  1. 市町を選ぶ。 山口県19市町から選び、登録簿上でその市町を運送区域に含む団体と登録車両を確認します。
  2. 確認できたGTFSを見る。 公式資料で市町名との関係を確認できたフィード、公開主体、データ基準日、アクセス条件を確認します。
  3. 同じ実日付で比べる。 岩国市関連・光市関連の2フィードについて、2026-04-06〜2026-04-12の予定運行便を切替なしで比較し、原本・日付・限界まで読みます。
  4. 協議前の確認メモにする。 選択した市町について、いま分かること、未確認事項、次に原本や関係機関へ確認することを一枚にまとめ、共有URLまたは印刷・PDF保存で共有します。

Value and current implementation

利用価値と現在の到達点

協議前にどう役立つか

行政・事業者が協議前に行う「公開情報の所在、日付、範囲の確認」を、市町単位の一つの入口で短縮します。分からないことも明示し、追加調査の出発点にできます。

現在できること

登録簿4PDFの機械可読化、19市町ビュー、公式GTFS状況、2フィードの実測比較を公開済みです。データ・コード・検証状況を第三者が同じURLから追跡できます。

新しく取り組んだこと

制度上の登録供給とGTFSの予定運行という単位の異なる資料を、日付の意味と限界を消さずに接続しました。単一の点数や順位へ丸めず、根拠を残しています。

サービス本体 / API文書

本作品が受け持つ手前の確認

GTFSを探す、地図で詳しく見る、計画案を分析する前に、登録供給・公式GTFS確認状況・日付・根拠・限界を19市町の同じ入口で揃え、共有・印刷できる協議前確認メモへ渡します。

比較対象の一次資料に書かれていない機能は、存在しないとは判断していません。本作品もGTFS-GOやLINKS Mobilysの分析機能を代替するものではありません。今回確認した3件だけから、国内唯一・網羅・優位とは主張しません。

Scope and limits

分かること／分からないこと

この作品で確認できること

  • 公表登録簿上の団体・登録車両と原本
  • 今回確認した公式資料におけるGTFSの公開状況
  • 岩国市関連・光市関連フィード全体の構造と、同じ7実日付の予定運行便
  • 表示値の基準日、内部有効期間、検証日、対象範囲

この作品だけでは分からないこと

  • 実際に運行した便、利用者数、定時性、便利さ
  • 市内だけに限定したGTFSの供給量
  • 県内すべての交通事業者・移動サービスの網羅
  • 公式資料で未確認だった地域にGTFSが存在しないかどうか

この画面は交通の充足度や市町の優劣を判定するものではありません。予定運行便は実運行や利用者数を表しません。
