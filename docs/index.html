Official GTFS / GTFS-JP status

GTFS/GTFS-JPの公式確認状況

—

国・山口県・市町の公式サイト、公式オープンデータサイト、公共交通オープンデータセンター（ODPT） を確認した結果です（確認日 2026-08-09）。GTFS本体のダウンロード・認証・解析は行っていません。

この確認が意味しないこと

公式資料がこの市町を運行対象として明記していることの確認であり、 市域全体・全事業者・全路線を網羅することは意味しません。

How to read

この数字が示すもの

確認できること

中国運輸局の登録簿に掲載された団体、登録車両数、軽内数、運送種別、有効期限です。

断定できないこと

運行頻度、予約可否、実際の稼働台数、一般の方が利用できるか、地域の交通充足度はこのデータだけでは分かりません。

市町値は県計として足し合わせない

複数市町を運送区域に含む団体の同じ車両が、それぞれの市町ビューに表示されます。市町別の値を合算すると重複する場合があります。
