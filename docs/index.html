How to read

この数字が示すもの

確認できること

中国運輸局の登録簿に掲載された団体、登録車両数、軽内数、運送種別、有効期限です。

断定できないこと

運行頻度、予約可否、実際の稼働台数、一般の方が利用できるか、地域の交通充足度はこのデータだけでは分かりません。

市町値は県計として足し合わせない

複数市町を運送区域に含む団体の同じ車両が、それぞれの市町ビューに表示されます。市町別の値を合算すると重複する場合があります。
