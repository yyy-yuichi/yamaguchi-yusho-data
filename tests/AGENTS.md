# Test area rules

このフォルダを変更・実行する担当は、ルートの`AGENTS.md`を先に読みます。
`internal/project_control/START_HERE.md`が存在する環境では、その案内に従って現在有効な正本も読みます。
上位の指示が必須とする文書が見つからない場合は、必要な指示が不足していることを報告します。

- テストは承認された完了条件と失敗条件を直接確認する。
- 保存済みの成功表示だけでなく、原本、生成結果、件数、ハッシュ、境界条件を再計算する。
- 既存テストを弱めたり削除したりして成功扱いにしない。
- 可能な限りネットワークなしで再現できるようにする。
- 検証役は失敗を黙って修正せず、`PASS`、`FAIL`、`INCONCLUSIVE`を分けて報告する。
- 全体テストと対象テストを区別し、実際に実行した範囲を明記する。
